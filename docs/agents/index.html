AI Agents & Skills

Flisk ships portable Agent Skills so a coding agent can run flisk doctor, bring a stack up, and diagnose Docker or Tilt failures with verified commands instead of guesses.

Install the skills

terminal
npx skills add flisk-sh/tdk-skills

# or, without npx: symlink into your tool's skills directory
curl -fsSL https://raw.githubusercontent.com/flisk-sh/tdk-skills/main/install.sh | sh -s -- --agent codex

The installer takes --agent claude|codex|opencode|cursor|agents and --global or --project (default). It only creates symlinks, never copies the markdown, and never uses sudo.

Skills

  • tdk-doctor — check or repair the environment and project configuration before flisk up.
  • tdk-troubleshoot — diagnose a failed flisk up, Docker or Tilt session.
  • layer-autoresearch — contributor experiment loop for the L1–L4 Docker layers.

Where each tool looks

  • Claude Code — .claude/skills/<name>/SKILL.md, or the optional plugin: /plugin marketplace add flisk-sh/tdk-skills
  • Codex — .agents/skills/<name>/SKILL.md
  • OpenCode — .agents/skills, .claude/skills or .opencode/skills
  • Cursor — .cursor/skills/<name>/SKILL.md
  • Other agents — copy the AGENTS.md rules template below. Skill auto-loading has not been verified for them.

Rules for your project repo

Copy rules/AGENTS.landscape.md into your project as AGENTS.md. It tells agents that Flisk is local-only, to run flisk doctor before flisk up, and not to hand-edit .autogenerated/ files. Don't copy the whole skill catalog into the project; install it once.
