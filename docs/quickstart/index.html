Quick Start

Install Flisk and start a ready-made app: an order tracker with an API, a Postgres database, a worker and a website.

You need Docker running and Tilt installed. Works on macOS, Linux, and Ubuntu in WSL2. On Windows, see Windows. No Docker? Try the one-line demo.

1. Install Flisk

terminal
curl -fsSL https://flisk.sh/install.sh | sh
flisk --version

You should see: A version number. If you see command not found, go to If it fails.

Install another way (AI agent, npm, pnpm, bun)
terminal
curl -fsSL https://flisk.sh/install.sh | sh

The AI agent line goes into your AI coding tool's chat. It installs Flisk for you. npm, pnpm and bun need Node.js {{ site.data.flisk.prereq_node }}.

2. Check your computer

terminal
flisk doctor

You should see: A list of checks. The last line starts with Doctor passed. Yellow lines are tips, not errors. If a check fails, doctor says what to install or start.

3. Start the app

terminal
git clone https://github.com/flisk-sh/flisk-example
cd flisk-example
flisk up

You should see: Flisk says what it is doing at each step, then prints links to the website and the API. Open one. Leave flisk up running. Lost the links? Run flisk networks in a second terminal. To stop everything, run flisk down.

If it fails

You seeDo this
flisk: command not foundThe installer printed an export PATH=… line. Run it, then open a new terminal.
Docker (or a compatible container runtime) is not runningStart Docker Desktop, or run colima start, or on Linux sudo systemctl start docker. Check with docker ps.
Tilt CLI is not installedOn macOS run brew install tilt. On Linux follow the Tilt install page. Check with tilt version.
Ports Flisk needs are takenAnother program uses the port. See Ports.
npm stops with EEXIST: file already existsYou had the old @tdk-landscape/tdk-cli-core package. Run npm uninstall -g @tdk-landscape/tdk-cli-core && npm install -g @flisk-sh/flisk.

Something else? Run flisk doctor, then look up the message in Troubleshooting.

More, when you need it

No Docker? Run the one-line demo

Needs Node.js {{ site.data.flisk.prereq_node }}. Nothing to install. It starts a small app (a website and an API) and opens it in your browser.

terminal
npx @flisk-sh/flisk demo
Make your own app from nothing

Make an empty project, then add an API to it.

terminal
mkdir my-service
cd my-service
flisk project --yes
flisk resource api --type backend --stack shop   # asks you to confirm
flisk project --check
flisk up shop

Add a website the same way. It is React unless you ask for Vue 3 with --framework vue (Flisk CLI 1.3.75 or newer):

terminal
flisk resource web --type frontend --stack shop                   # React + Vite (default)
flisk resource web --type frontend --framework vue --stack shop   # Vue 3 + Vite

Flisk checks .flisk/project.json and writes its files into .flisk/.flisk-out/. To start one service before another, list it in dependsOn.

Windows

Best way: use Ubuntu in WSL2 and follow the three steps above. Here is the WSL2 Ubuntu setup.

Plain Windows (AMD64) can install Flisk and run flisk demo. It cannot start a Docker app. Install from PowerShell:

PowerShell
irm https://flisk.sh/install.ps1 | iex

Want to read the script before you run it?

PowerShell
Invoke-WebRequest https://flisk.sh/install.ps1 -OutFile install-flisk.ps1
powershell -ExecutionPolicy Bypass -File .\install-flisk.ps1

Close PowerShell and open a new window. Then check:

PowerShell
flisk --version
flisk runtime --check-assets
flisk doctor

On plain Windows, flisk doctor says that starting a Docker app needs WSL2 Ubuntu. That is expected. There is no Windows ARM64 build.

Download the files by hand

Download the program, its engine files and the checksums yourself. The program looks for a flisk-cli/ folder next to it.

Windows AMD64

The latest release includes the Windows CLI and the PowerShell installer verifies its checksum. On native Windows, flisk demo and projects whose services each declare a command run as local processes. For a Docker stack, native Windows supports CLI inspection only (flisk --version, flisk runtime --check-assets, flisk doctor); to start one, follow the WSL2 Ubuntu setup.

PowerShell
irm https://flisk.sh/install.ps1 | iex
terminal
os=$(uname -s | tr A-Z a-z); arch=$(uname -m | sed "s/x86_64/amd64/;s/aarch64/arm64/")
base=https://github.com/flisk-sh/releases/releases/latest/download
curl -fsSL -O "$base/flisk-$os-$arch" -O "$base/flisk-cli-engine.tar.gz" -O "$base/checksums.txt"
shasum -a 256 -c --ignore-missing checksums.txt
mkdir -p ~/.local/bin/flisk-cli
install -m 755 "flisk-$os-$arch" ~/.local/bin/flisk
tar -xzf flisk-cli-engine.tar.gz -C ~/.local/bin/flisk-cli --strip-components=1

The files come from flisk-sh/releases.

Try Flisk inside Docker Compose

Do this if you do not want to install Flisk on your computer.

terminal
git clone https://github.com/flisk-sh/flisk-docker-compose-example.git
cd flisk-docker-compose-example
docker compose run --rm flisk flisk --version
docker compose run --rm flisk flisk project --yes
I have a Premium or Enterprise key

Flisk is free and needs no key. A key is only for paid extras, such as Verdaccio (a local npm registry) and Sablier (stops services nobody is using). Playwright, C4 and AGENTS.md are free when generated in your repo. A key is needed only to download their implementations.

Run this before flisk up:

terminal
export FLISK_LICENSE_KEY=<your-license-key>

To keep it, add that line to ~/.zshrc or ~/.bashrc. One key covers up to {{ site.data.flisk.premium_project_limit }} projects. Enterprise has no limit. If the key is missing, expired or cannot be checked, Flisk keeps running with the free engine.
