Quick Start

Three steps: install, check, run. At the end, a real app runs on your computer.

Step 1. Install

Pick one tab. Not sure? Use curl. On Windows, see Windows below.

terminal
curl -fsSL https://flisk.sh/install.sh | sh
Please install Flisk and configure its local MCP server for this agent: {{ '/llms.txt' | absolute_url }}
{{ site.data.flisk.install_npm }}
# run without installing
{{ site.data.flisk.install_npx_version }}

# or make a new project right away
{{ site.data.flisk.install_npx_project }}
{{ site.data.flisk.install_pnpm }}
{{ site.data.flisk.install_bun }}

Use an AI coding tool? Open the AI agent tab and paste that line into its chat. It installs Flisk for you. The npm, pnpm and bun tabs need Node.js {{ site.data.flisk.prereq_node }}. The curl tab does not.

Now check it worked. You should see a version number.

terminal
flisk --version

Step 2. Check your computer

terminal
flisk doctor

It looks at your computer and tells you what is missing. Fix what it says. Run it again. Stop when every line is green.

For the example in step 3 you need two things:

  • Docker, installed and running
  • Tilt, installed

Works on macOS, Linux, and Ubuntu in WSL2.

Step 3. Run the example

terminal
flisk project example
cd flisk-example
flisk up
  1. The first line copies a ready-made app: an order tracker with an API, a Postgres database, a worker and a website.
  2. The second line goes into its folder.
  3. The third line starts it. Leave it running.

When the app is ready, flisk up prints its links. Open one in your browser. Lost the links? Run flisk networks in a second terminal.

Done

The app runs on your computer. A teammate who copies the repo runs the same lines and gets the same app.

Only want a look? One line

Have Node.js {{ site.data.flisk.prereq_node }}? Run this. Nothing to install. No Docker needed.

terminal
npx @flisk-sh/flisk demo

It starts a small app (a website and an API) and opens it in your browser.

What you will see

Flisk checks your computer first, then says what it is doing at each step.

zsh: flisk doctor && flisk up
Docker or Tilt missing? See what Flisk says

flisk up stops before it starts anything and tells you what to install:

terminal
$ flisk up

Flisk can't start - missing prerequisites:

❌ Docker (or a compatible container runtime) is not running

💡 Suggestions:
   → Start Docker Desktop, then verify with: `docker ps`
   → Or start Colima: `colima start`
   → Or start the Docker service on Linux: `sudo systemctl start docker`
   → Setup guide: https://flisk.sh/docs/quickstart/

❌ Tilt CLI is not installed

💡 Suggestions:
   → Install Tilt: `brew install tilt` (macOS)
   → Or download from: https://docs.tilt.dev/install.html
   → Verify with: `tilt version`

Run `flisk doctor` for a full environment check.

Do what it says. Run flisk doctor. Then run flisk up again.

More, when you need it

None of this is needed for the three steps above. Open what you need.

Make your own app from nothing

Make an empty project, then add an API to it.

terminal
mkdir my-service
cd my-service
flisk project --yes
flisk resource api --type backend --stack shop   # asks you to confirm
flisk project --check
flisk up shop

Add a website the same way. It is React unless you ask for Vue 3 with --framework vue (Flisk CLI 1.3.75 or newer):

terminal
flisk resource web --type frontend --stack shop                   # React + Vite (default)
flisk resource web --type frontend --framework vue --stack shop   # Vue 3 + Vite

Flisk checks .flisk/project.json and writes its files into .flisk/.flisk-out/. To start one service before another, list it in dependsOn.

Windows

Best way: use Ubuntu in WSL2 and follow the three steps above. Here is the WSL2 Ubuntu setup.

Plain Windows (AMD64) can install Flisk and run flisk demo. It cannot start a Docker app. Install from PowerShell:

PowerShell
irm https://flisk.sh/install.ps1 | iex

Want to read the script before you run it?

PowerShell
Invoke-WebRequest https://flisk.sh/install.ps1 -OutFile install-flisk.ps1
powershell -ExecutionPolicy Bypass -File .\install-flisk.ps1

Close PowerShell and open a new window. Then check:

PowerShell
flisk --version
flisk runtime --check-assets
flisk doctor

On plain Windows, flisk doctor says that starting a Docker app needs WSL2 Ubuntu. That is expected. There is no Windows ARM64 build.

I have a Premium or Enterprise key

Flisk is free and needs no key. A key is only for paid extras, such as Verdaccio (a local npm registry) and Sablier (stops services nobody is using). Playwright, C4 and AGENTS.md are free when generated in your repo. A key is needed only to download their implementations.

Run this before flisk up:

terminal
export FLISK_LICENSE_KEY=<your-license-key>

To keep it, add that line to ~/.zshrc or ~/.bashrc. One key covers up to {{ site.data.flisk.premium_project_limit }} projects. Enterprise has no limit. If the key is missing, expired or cannot be checked, Flisk keeps running with the free engine.

npm says EEXIST (you had the old tdk package)

Flisk used to be called @tdk-landscape/tdk-cli-core. The old package blocks the new one, so npm stops with EEXIST: file already exists and you get no flisk command. Remove the old one, then install Flisk:

terminal
npm uninstall -g @tdk-landscape/tdk-cli-core && npm install -g @flisk-sh/flisk

The curl install does not have this problem.

Download the files by hand

Download the program, its engine files and the checksums yourself. The program looks for a flisk-cli/ folder next to it.

Windows AMD64

The latest release includes the Windows CLI and the PowerShell installer verifies its checksum. On native Windows, flisk demo and projects whose services each declare a command run as local processes. For a Docker stack, native Windows supports CLI inspection only (flisk --version, flisk runtime --check-assets, flisk doctor); to start one, follow the WSL2 Ubuntu setup.

PowerShell
irm https://flisk.sh/install.ps1 | iex
terminal
os=$(uname -s | tr A-Z a-z); arch=$(uname -m | sed "s/x86_64/amd64/;s/aarch64/arm64/")
base=https://github.com/flisk-sh/releases/releases/latest/download
curl -fsSL -O "$base/flisk-$os-$arch" -O "$base/flisk-cli-engine.tar.gz" -O "$base/checksums.txt"
shasum -a 256 -c --ignore-missing checksums.txt
mkdir -p ~/.local/bin/flisk-cli
install -m 755 "flisk-$os-$arch" ~/.local/bin/flisk
tar -xzf flisk-cli-engine.tar.gz -C ~/.local/bin/flisk-cli --strip-components=1

The files come from flisk-sh/releases.

Try Flisk inside Docker Compose

Do this if you do not want to install Flisk on your computer.

terminal
git clone https://github.com/flisk-sh/flisk-docker-compose-example.git
cd flisk-docker-compose-example
docker compose run --rm flisk flisk --version
docker compose run --rm flisk flisk project --yes
