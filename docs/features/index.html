Write less

One service.json per service

Describe each service in one small file. Flisk generates the Dockerfile, the Compose entry, the Traefik routes, the health check and the Tiltfile from it, so you never hand-write a docker-compose.yml or an nginx.conf.

terminal
flisk resource orders-api --type backend --stack shop --yes

service.json reference

Wired for you

DATABASE_URL, the API address your frontend calls, and missing secrets such as JWT_SECRET are generated and passed to each service. You do not copy them between files.

How it works

Start from what you have

Have a docker-compose.yml? flisk import reads it and writes a service.json for each service. Add --dry-run to preview first.

terminal
flisk import . --dry-run

Migrate to Flisk

Run it

One command, one address

flisk up starts your database, your services and a local gateway. Services start in health-checked dependsOn order, and each one gets a *.localhost address that Flisk prints.

terminal
flisk up shop

Quick Start

Hot reload while you code

Tilt updates a running container when you save a file. There is no rebuild step between your edit and the result.

How it works

No Kubernetes, and Docker only when you need it

Docker and Tilt run the stack without a local cluster. A small app whose services each set a command runs as plain local processes with no Docker.

Check it

Generated files you can check

Flisk records what it wrote and refuses to start when a generated file was edited by hand. flisk config verify reports any drift between your service.json files and the generated ones.

terminal
flisk config verify

Generated files and drift checks ↗

Plain-words setup check

flisk doctor checks only what your project uses and says what is missing, with a fix for each problem.

terminal
flisk doctor

Work with AI

Built for AI helpers

flisk mcp gives Claude Code, Codex, Cursor and other agents tools to create resources, start the stack and read status and logs. flisk project adds the Flisk skills and an AGENTS.md to your project.

terminal
flisk connect claude --dry-run

AI agents and skills

Runs AI agents too

An agent resource gets durable checkpoints that survive restarts, session routing by the x-session-id header, and /health and /ready checks, next to its tools and database.

terminal
flisk resource bot --type agent --stack shop --yes

Stay in control

Leave any time

Your own Dockerfiles, service.json files and code are never touched. flisk eject writes EJECTED.md, which explains how to run the stack with plain tilt up.

terminal
flisk eject

No lock-in

Free core

The CLI is MIT licensed and needs no key to run flisk up. Premium extras are optional, at ${{ site.data.flisk.team_price }} per developer per month.
