Documentation

Flisk starts every service of your app on your computer with flisk up. Each service is described by one service.json file.

terminal
npx @flisk-sh/flisk demo

Needs Node.js {{ site.data.flisk.prereq_node }}. Nothing to install, no Docker. It starts a website and an API and opens them in your browser. To install Flisk and run a full app, follow the Quick Start.
