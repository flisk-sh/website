What is Flisk CLI?

Flisk CLI starts services on your machine. It is not a deploy and not a Compose file: describe each service in service.json, then run flisk up. Production deployment stays with Helm, Argo CD, or Kustomize. Start with the quickstart, then see how Flisk works alongside Helm.

Describe each service in service.json, then use Flisk to generate the local Docker and Tilt setup. See the Helm handoff for cluster deployment.

  • Dockerfile with optimized L1-L4 golden layering
  • Vite and TypeScript configuration per app type, for React (default) or Vue 3 frontends
  • nginx reverse proxy rules and Traefik routes
  • Environment files and .npmrc wired to the local registry
  • Tiltfile for local orchestration
  • An AGENTS.md in each .autogenerated/ folder that tells coding assistants not to edit generated files
