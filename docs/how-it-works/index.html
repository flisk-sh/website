How it works

You describe each service in one small file. flisk up reads those files, writes the setup around them and starts everything on your computer.

What runs where

The steps

StepWhat happens
1. DescribeEach service has one service.json: its name, type, port and health check. A service with a "command" runs as a plain process.
2. Generateflisk up finds every service.json and writes the Tiltfile, the Compose file and the Traefik routes into .flisk/.
3. StartLocal-process services start on your machine. Container services are built and started by Tilt on Docker, and reload when you save a file.
4. ReachOn the Docker path, Traefik puts one address in front of every service. Flisk prints the URLs when they are ready.
5. Checkflisk status shows which services are healthy, and flisk logs -s <name> shows why one is not.

The long version, with every file and function, is How flisk up works ↗ on GitHub. If something does not start, see Troubleshooting.
