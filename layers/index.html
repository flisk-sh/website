# golden layers [l1 to l4]

Rebuilds that only redo what you changed.

Every service Flisk sets up builds in the same four layers. The slow, rarely changing steps sit at the bottom and are reused, so editing your code rebuilds only from the compile step up. The details below are for the curious.
