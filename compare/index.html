Choose the local workflow that fits.

Flisk CLI turns service.json per service into a local Docker stack. Tilt watches services and live-updates containers as you code. It is not a deploy tool and not a Compose replacement. Production stays on Helm.

Full comparison and known limits ↗

Compose fits a few services you already wrote. Tilt fits teams that maintain their own Tiltfile. Skaffold, Garden, and DevSpace target a cluster. Use the tool that matches your workflow.

Which tool is right for you?

Choose Flisk if you…

Want a manifest-driven local Docker workflow with selective startup. Flisk is designed so flisk doctor and flisk up replace a setup wiki; onboarding time has not been measured on a hiring cohort.

Choose Devbox if you…

Want Nix power without learning Nix language. Need JSON configuration. Prefer simple package management. Want cloud deployment with Jetify Cloud. Are building for cloud-native teams with budget for managed services.

Choose Devenv if you…

Already know Nix or willing to learn. Need maximum reproducibility. Want full environment declaration (languages, services, processes). Are working with complex monorepos. Need fine-grained control over every aspect of your dev environment.

Choose Garden if you…

Have Kubernetes expertise in-house. Need production-like environments for integration testing. Employ a dedicated platform team with time to maintain YAML pipelines. Flisk complements this setup nicely for the fast local loop, by the way.

Choose Cloud CDEs if you…

Have budget for cloud spend. Need instant onboarding for remote teams. Want standardized environments without local machine variations. Don't mind working offline or managing cloud costs. Value convenience over control.
