{% comment %} The whole onboarding in one block. Used on /docs/ and /docs/quickstart/. {% endcomment %}
terminal
curl -fsSL https://flisk.sh/install.sh | sh
flisk doctor
git clone https://github.com/flisk-sh/flisk-example
cd flisk-example
flisk up

Line 1 installs Flisk. Line 2 checks your computer: fix what it says. The rest copy a ready-made app and start it. You need Docker running and Tilt installed. flisk up prints links when the app is ready. Open one. Done.
