Stacklytics. How long Flisk takes to bring each stack up.

Flisk's own CI scaffolds and starts every language, framework and resource type it supports on a fresh GitHub runner every night, and publishes the times here. Try one with npx @flisk-sh/flisk demo.

Not a runtime benchmark. A cold start here is the whole first flisk up on a fresh CI runner: pulling and building the image, installing dependencies and starting the container until the route answers. That is mostly Docker and package-install time, so it says how quickly Flisk gets a stack running, not which language or framework runs faster. Each number is one CI run: the same Bun stack took 47 s in one run and 27 s in the next, so differences of a few seconds are noise.
