Configuration generation

One service.json becomes {{ site.data.flisk.files_per_service }} production-grade files per service - written correctly and kept in sync.

01

TypeScript config

tsconfig.json with proper paths, includes and compiler options for backend, frontend and libraries.

02

Vite configuration

vite.config.ts for local, Docker and production builds. React by default, or Vue 3 with "framework": "vue".

03

Docker and Compose

Multi-stage Dockerfile with golden image layering. Compose orchestration per service.

04

nginx proxy

Reverse proxy rules with Traefik integration for pretty local URLs.

05

Environment files

.env files with service-specific variables, database URLs and internal dependencies.

06

Package manager

.npmrc and bunfig.toml wired to the local Verdaccio registry and npm.

07

AGENTS.md guard (Premium)

Built on Tilt — {{ site.data.flisk.tilt_stars }} GitHub stars — for a feedback loop measured in seconds.

08

Hot reload

Instant code sync with Tilt live_update. No container rebuilds while you type.

09

Selective startup

Run 5 services instead of {{ site.data.flisk.scale_plain }}. Start only what your task touches.

10

Auto-discovery

Finds every service.json in your directory tree. Zero manual registration.

Manifest synthesis

Docker only

Pure Docker + Tilt. No cluster, no control plane, no YAML maze.

Traefik integration
